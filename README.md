# PepMat
The peptide combination scheme was screened based on the peptide-gas affinity dataset, the peptide chip was designed, and the artificial affinity dataset was constructed. After that, the statistical model, the machine learning model, the deep learning model, and the deep learning model based on the peptide chip were realized respectively.
